# CH32V003 UART IAP Bootloader

A compact UART-based In-Application Programming (IAP) bootloader for the WCH CH32V003 RISC-V microcontroller. Flash new firmware over a serial connection at 460800 baud with no additional hardware programmer required.

## Features

- **Minimal footprint** — bootloader fits in **1860 bytes** of flash
- **UART firmware update** — receive firmware at 460800 baud via USART1
- **Fast flash programming** — uses CH32V003's 64-byte fast-program buffer
- **Built-in verification** — checksum validation on every packet + post-transfer flash verify
- **Status LEDs** — PC4 and PC7 configured as outputs for indication

Communication runs at **460800 baud, 8N1**, no hardware flow control.

This project uses the **MounRiver Studio** toolchain (riscv-none-embed-gcc). The Makefile is generated by MounRiver Studio IDE.

### Compiler Flags

```
-march=rv32ecxw -mabi=ilp32e -Os -ffunction-sections -fdata-sections
-nostartfiles -T Link.ld --specs=nano.specs --specs=nosys.specs
```

The `-Os` flag optimizes for size, and `--gc-sections` removes unused code. The linker script (`Ld/Link.ld`) limits the bootloader to 1920 bytes of flash.
